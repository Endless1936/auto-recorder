# Icon provenance

The app icon was generated with the built-in image_gen tool and selected by the project owner. Source: `AppIcon.png`; native sizes: `AppIcon.icns`.

<details><summary>最终生成提示词</summary>

Use case: logo-brand. One finished macOS app icon for Auto Recorder, a native screen recorder with automatic cursor-following zoom. Single centered icon, 1024x1024 square, no mockup or presentation. Keep the approved palette and material consistent: deep graphite #202326 native rounded-square tile, soft solid mint #A6EBC4 mark. Tile occupies 84% with even genuinely transparent margins. Very restrained subtle bevel, crisp geometry, generous negative space, robust shape readable at 16/32px. No red, white/ivory tile, blue, purple, neon, glow, sparkles, watermark, scene, explanatory labels or wordmark. Make the motif look designed as a cohesive application logo, not a cluster of interface buttons. Motif: a large bespoke solid mint arrow cursor pointing upper-left, with softly rounded external corners and a crisp tip. Integrate one elegant short curved trailing stroke into its lower-right tail to suggest intelligent smooth following and movement; the trail must belong to the same cohesive mark. No frame, no circles, no camera, no lettering. Asymmetric but optically centered, energetic, minimal, recognizable at small scale. Not the stock macOS cursor shape.
