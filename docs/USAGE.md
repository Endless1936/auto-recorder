# 使用说明

## 录制

选择整个屏幕、单个窗口或选定区域；再次点击选区卡片可重新框选。电脑声音和麦克风独立开关，图标中的实色填充显示电平。录制设置支持 HEVC／ProRes 422、30／60 fps。

保存位置默认是桌面的 `Auto Recorder`，可以更改。每次自动建立“录屏 年-月-日 时.分.秒”工程文件夹。录中从菜单栏暂停、继续或停止；关闭录制面板不会退出应用。

首次需要屏幕与系统音频录制权限；开启麦克风时申请麦克风权限。系统还可能询问保存文件夹的访问权限，无需完整磁盘访问或辅助功能权限。

## 工程与剪切

工程包含原片 `.mov` 与 `project.json`，保留鼠标轨迹、镜头参数和剪切排序。修改自动保存，不改写原片；请将整个文件夹一起移动或备份，用“打开工程”继续编辑。

时间轴用于播放定位，也支持分割、裁首尾、删除和拖动重排。“返回录制”保留工程；“导出视频”才生成最终成片，可选择名称与位置。取消导出保留原片、工程及已有目标文件。

## 自动放大与取景

开启自动放大后，点击聚焦；鼠标静止 1 秒后，从当前取景位置平滑恢复全景。

- 初始四点是开始放大、达到峰值、开始缩回和恢复全景。中间点可独立调整，两端固定 1×；可添加更多锚点，倍率范围 1×～3×。
- 左右拖动控制时间，上下拖动控制倍率；接近其他点的高度时吸附，Option 暂停吸附。
- 在曲线空白处拖动框选，拖所选节点一起左右移动或升降；Shift 点击追加选择。成组调整保留时间间距和倍率差，两端全景节点只左右移动。
- 选中节点时，Delete 删除节点，并将前后两点之间的运动简化为直线平移；重新选中时间轴素材后，Delete 才删除素材。两端全景节点保留，删除和调整支持撤销。
- 开启取景辅助层可看完整原画和当前取景框。暂停后拖框可平滑修正前后约一秒的取景位置，原始轨迹保留；拖四角改倍率，曲线同步变化。关闭辅助层即正常预览；辅助层不进入导出。
- 右侧菱形加号在当前时刻添加锚点，添加本身不改变画面。加减号用于添加／移除整个放大段。
- ↑／↓ 跳到前一个／后一个锚点或片段边界；定位锚点时，预览与曲线同步选中。

录屏已经包含鼠标，不能单独改变指针样式或位置；数字放大不会增加原片细节。编辑仅含剪切与取景，没有特效、转场、音效或多轨。

## 快捷键与更新

| 快捷键 | 操作 |
| --- | --- |
| ⌘⇧R | 开始／停止录制 |
| ⌘⇧P | 暂停／继续录制 |
| 空格 | 编辑器播放／暂停 |
| B | 在播放头分割 |
| Delete | 删除当前选择 |
| ⌘Z | 撤销 |
| ⌘＋／⌘− 或 ⌘＋滚轮 | 同步缩放视频与动画时间轴，最小 100% |
| Shift＋滚轮 | 横向浏览放大后的时间轴 |

更新前停止录制并退出应用，再替换旧版本。卸载时将应用移入废纸篓即可，录屏工程由你自行保留或删除。
